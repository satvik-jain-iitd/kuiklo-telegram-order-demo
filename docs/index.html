How it works

One n8n workflow, three local services, one box.

Telegram calls a 21-node n8n workflow on an Oracle Cloud box. Speech-to-text, the FAQ bot and the voice service run on the same box. Nothing leaves it except Telegram, the Sarvam voice call, and the DeepSeek fallback for hard-to-parse orders.

n8n workflow local service on the same box external call, only when rules fail Dashed box: everything inside runs on one Oracle machine

Leaves the box

Telegram messages. One Sarvam API call per new voice line (then cached). One DeepSeek v3.2 call via OpenRouter when rules cannot read the order.

Stays on the box

Every voice note, every transcript, the FAQ knowledge base, the catalog, sessions and orders. Secrets sit in a 0600 file on the box, never inside n8n nodes.

Kill switch

One Config flag stops the whole bot. Fees, swap window, model names and the greeting text are Config values, not buried in code.

Transparency and fairness rules

The customer always sees the full bill first.

These rules come from the spec and each one has a unit test behind it.

  • Every charge is a line item in the summary. No hidden fee.
  • The summary is shown before confirmation. Confirmation is a separate tap.
  • Any change after confirmation shows before and after, line by line.
  • Delivery fee and handling fee do not change silently. If they change, show it.
  • Payment mode and delivery promise are always shown.
  • Every price is labeled "demo" in the demo build.
  • The bot never says a price is final when it is a demo value.
  • Options such as "change order" are shown as buttons, never hidden. Typed "haan" still works as a fallback.
Privacy and safety

Built so the founder can show it without worry.

Voice clone, with consent

The clone is used only after Shyam Gupta's consent is on file in a private folder. Every voice reply carries the caption "AI-generated voice (Shyam Gupta ki awaaz)". It is never used to make a customer believe they are speaking to him personally. Without consent the bot falls back to text.

Stock is never shown

The catalog is loaded through a column allowlist. The stock flag only hides unavailable items and is dropped before anything else runs. "Kitna stock hai?" gets a refusal: "Stock ki jaankari main nahi de sakta." Tested in T-06 and T-22.

Phone is masked

Phone numbers show only the last two digits in every customer message (98xxxxxx10) and are stored masked. Tested in T-10.

Test chat only

No real customer Telegram IDs are stored in the repo. Sessions live in n8n static data for the demo only. Real payments and real dispatch are out of scope.

Secrets stay off the workflow

Bot token, Sarvam key and voice id live in a 0600 file on the Oracle box. n8n nodes never hold them. The STT, FAQ and voice servers listen on 127.0.0.1 only.

Caps on spend

200 characters per voice message, 100 voice messages per day. Over the cap the same message goes out as text. Audio is cached by text hash, so a repeated line costs nothing again.

Built on Kuiklo's own words

The FAQ bot answers from kuiklo.com, not from guesses.

31 question and answer pairs were taken from Kuiklo's public pages on 8 Oct 2026. The bot finds the closest 3 with MiniLM embeddings and writes a Hinglish reply with gemma3:4b. A question that scores under 0.30 is turned away with "Yeh sawal Kuiklo ke baare mein nahi lag raha."

Are there delivery charges on Kuiklo? Any hidden fees?
No. Kuiklo says there are zero delivery charges. What you see at checkout is exactly what you pay. No hidden fees, no platform fees, no surge pricing, no convenience fee.
Which city does Kuiklo serve? Is Kuiklo available in my area?
Kuiklo operates in Patna only. It serves major localities in Patna, including Kankarbagh, Boring Road, Fraser Road, Kidwaipuri, Bailey Road, Rajendra Nagar, and more.
Can I cancel or change my order after placing it?
Changes or cancellations are only possible within the first 60 seconds after placing an order, because of the rapid fulfilment model. Once an order is packed for delivery, it cannot be cancelled.
What payment methods does Kuiklo accept?
Credit and debit cards, digital wallets (such as Apple Pay, Google Pay, Amazon Pay, Mobikwik), UPI, LazyPay, Paytm, and cash on delivery in select areas. Payments go through RazorPay as the payment gateway.
