# Demo D1: the ten-minute voice order

Audience: Shyam Gupta, on his phone, in the @Kuicklobot chat. Unofficial demo. Mock prices.

What you can see:
- A voice note in Hinglish becomes an order with a full price table.
- Brand chosen by buttons. Every charge shown before Confirm.
- A one-minute window to change a brand, with before and after lines.
- Questions answered from the order and from kuiklo.com text. Stock questions refused.
- Short replies in the founder's cloned voice, labeled AI-generated.

Before you start (operator):
- `curl 127.0.0.1:8787/health` on Oracle returns `{"ok": true}`.
- Workflow `qAUgmP8Q7cvciLX9` is active. `kill_switch` is false.
- Sarvam credits remain (35 lines cost ₹2.34 so far).
- Keep voice notes under 15 s. STT runs at about 0.45x real time.

The script (about ten minutes):
| Minute | Step | What to do | What should happen |
|---|---|---|---|
| 0 | /start | tap Start | Devanagari welcome text, then a voice bubble with the greeting and the caption "AI-generated voice (Shyam Gupta ki awaaz)" |
| 1 | voice order | say "ek kilo atta, do roti, teen kilo bhindi, kal subah" | "Maine yeh samjha:" with three items and "Delivery: kal (9 Oct)" |
| 2 | brand buttons | the bot asks "Atta kaunsa brand chahiye?" (voiced); tap Aashirvaad | "✔️ Atta: Aashirvaad Select Sharbati" |
| 3 | details | answer name, phone, tap an area | each question is one message; phone shows as 98xxxxxx10 |
| 4 | summary | read the `<pre>` table | subtotal ₹188, delivery ₹25, handling ₹5, TOTAL ₹218, all marked demo, COD |
| 5 | confirm | tap ✅ Confirm order | order id ORD-20261008-0001, the one-minute notice, two buttons |
| 5.5 | swap | tap 🔄 Order change karna hai, tap Atta, tap Pillsbury | "Aashirvaad 1 kg ₹48 → Pillsbury 1 kg ₹52 (+₹4)", "TOTAL: ₹218 → ₹222"; tap ✅ Change confirm karein |
| 7 | FAQ | type "delivery charge kitna hai?" | a Hinglish answer from kuiklo.com text (allow up to 45 s) |
| 8 | stock refusal | type "kitna stock hai atta ka?" | "Stock ki jaankari main nahi de sakta." |
| 9 | late swap | tap the old 🔄 button again | "⏱️ Change ka time nikal gaya..." |
| 10 | close | say thanks; point to the repo and this docs tree | done |

If something fails:
- No voice bubble: the same text arrives as a message. Say so and continue.
- STT is slow: wait; a 10 s note takes about 5 s. Do not resend.
- A button does nothing: it belongs to an old state. The bot says so. Send a new order.
