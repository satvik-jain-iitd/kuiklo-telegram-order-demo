# ADR-009: Every string sent to Sarvam is Devanagari.

Status: accepted, 2026-10-08

Context: the owner heard the first voice lines. Hinglish in Latin letters was mispronounced.
Hindi in Devanagari was pronounced well. The greeting text he gave was then rewritten in
Devanagari. Decision: every string sent to Sarvam (greeting, follow-up questions, any future
line) is Devanagari with no Latin letters. `voice.py` refuses any other text, and n8n then
sends plain text. T-31 checks every voice line the brain can produce. Product names have a
Devanagari table in `brain.js`. Trade-off: two copies of each question, one for voice and
one for the text caption. Consequence: the clone sounds right. A slip is caught by a test,
not by the customer.
