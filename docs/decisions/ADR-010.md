# ADR-010: Brand is asked per item, never assumed.

Status: accepted, 2026-10-08

Context: the first build picked the first catalog row as the default brand. The owner said:
the brand must be asked for each item, not assumed. Decision: when the catalog has more
than one brand for a product, the bot asks "<Item> kaunsa brand chahiye?" with one button
per brand showing price per unit, plus "Koi bhi chalega". A brand typed with the item
("pillsbury atta") is applied and not asked again. Items with one brand are not asked.
Trade-off: one more tap per multi-brand item. Consequence: the summary never shows a brand
the customer did not pick. A related fix the same day: a brand question about an ordered
item ("atta ke brands?") is answered, not read as a new order, unless the text carries a
quantity.
