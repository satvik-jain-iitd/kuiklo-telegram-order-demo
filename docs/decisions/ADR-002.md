# ADR-002: bhavna.ai STT on Oracle through CTranslate2 int8 and faster-whisper.

Status: accepted, 2026-10-08

Context: the owner named bhavna.ai as the STT and Oracle as the box. bhavna.ai on the Mac
uses MLX, which runs only on Apple silicon. Oracle is aarch64 Linux, 4 CPU, no GPU, Python
3.9. Decision: serve the same Apex weights from the CT2 int8 copy that bhavna.ai ships
(`models/apex-ct2-int8`, 773 MB) with faster-whisper 1.2.1. Same decode settings: language
en, temperature 0, no timestamps, beam size 1, no VAD. One HTTP service on 127.0.0.1:8787.
Trade-off: about 0.45x real time on CPU (70 s in 29.4 s). One request at a time is safe.
Consequence: a short Telegram note returns in about 9 s. Long notes feel slow; the demo
keeps notes short.
