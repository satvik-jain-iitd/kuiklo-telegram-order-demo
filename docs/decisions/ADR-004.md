# ADR-004: Sessions and orders in workflow static data.

Status: accepted, 2026-10-08

Context: the spec planned `store.py` with orders.csv or SQLite. On n8n there is no local
file. A database server is out of scope. Decision: `$getWorkflowStaticData('global')` holds
`sessions[chat_id]`, `orders[]` and the daily `seq` counter. Phone is stored masked.
Trade-off: static data can be lost on workflow re-import, and it is not a record system.
Consequence: good for a demo chat. Order writes to a sheet or SQLite are the next step
(backlog E11) before any real use.
