# ADR-008: Sarvam cloned voice, cached by text hash, capped per message and per day.

Status: accepted, 2026-10-08

Context: P7 asks for follow-up questions in the founder's voice, labeled AI, only with
consent (G1). Sarvam bills ₹3 per 1,000 characters and gives ₹100 free credits. Decision:
`voice.py` calls Sarvam `POST /voices/clone` (voice_id, hi-IN, mp3) and sends the mp3 with
Telegram `sendVoice`. Audio is cached on disk by text hash, so the greeting costs once.
Caps: 200 characters per message, 100 voice messages per day. Voice is used only for the
greeting and the short follow-up questions. Summaries, lists and FAQ answers stay text.
On any failure, n8n sends the same text with the same buttons. The caption always starts
with "AI-generated voice (Shyam Gupta ki awaaz)". Trade-off: a Sarvam key and a voice id
live in `~/bhavna-stt/.env`. Consent is the owner's word today; Shyam Gupta's own note is
still to be added. Consequence: 35 lines cost ₹2.34. The demo stays within the free tier.
