# ADR-006: DeepSeek v3.2 as the LLM fallback model.

Status: accepted, 2026-10-08

Context: live tests used free OpenRouter slugs first. The free llama slug returned 404.
The free gemma slug returned 429. Decision: `llm_model` in Config is
`deepseek/deepseek-v3.2`. The OpenRouter node continues on error, so a model failure never
stops the flow. Trade-off: not free. Measured cost about 0.00004 USD per extraction call,
which is close to nothing. Consequence: the fallback works in live chat. The model name is
one Config value and can change without a code edit.
