# ADR-005: Rules first, LLM only when rules find nothing.

Status: accepted, 2026-10-08

Context: the owner asked for extraction by rules, with an OpenRouter LLM as fallback.
Decision: `extract()` in `brain.js` does the work. It reads digits and Hindi number words
(ek, do, aadha, dedh, dhai). It reads units (kg, g, pcs, dozen, packet). It maps product
aliases and two-word names (moong dal, shimla mirch). It reads date words (aaj, kal,
parso) and slot words. The LLM runs only when rules found no items, there are unknown
words, and the text is not `/start`. The LLM reply is parsed as a JSON array. Any parse
problem gives no items. Trade-off: two code paths to test. The LLM prompt knows a shorter
product list than the rules. Consequence: most orders cost nothing and give the same
result every time. The LLM catches odd spellings only.
